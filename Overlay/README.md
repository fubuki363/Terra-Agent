# Terra Agent 悬浮助手

这是面向原版 Terraria 的独立 Windows 悬浮助手。它不注入游戏、不写入进程内存，也不改动
角色或世界存档。当前调用模型为 `deepseek-flash`。

## 使用

1. 双击 `TerraWikiOverlay.exe`，首次启动会在屏幕中央展开完整问答面板。
2. 启动原版 Terraria。
3. 点击悬浮球，输入问题并按 Enter。
4. 按住 Shift+Enter 可以在问题中换行。
5. 使用 `Ctrl+Shift+T` 可以随时展开或收起面板。

1.4.0 将所有功能页放入同一个界面：设置、API Key、用量、游戏权限、查找与导航、常用速查及图鉴
工具栏共享字体、按钮、表单、列表和弹窗样式，不再打开旧的原生设置窗口或定位列表。
“设置 → 常规 → 外观”提供浅色、夜间、跟随系统三种选择；右上角太阳/月亮按钮可快速切换。
选择会保存到本机，重启后恢复；跟随系统会自动响应 Windows 明暗设置。
主题同时应用到各功能页、图鉴网页、悬浮球与右键菜单，切换功能页不会退回另一套配色。

1.3.0 重做了对话界面，使用 DeepSeek Harness 官方主题变量，并适配其消息布局、输入区、
思考折叠、工具调用和处理过程。左侧可搜索与切换会话；窄窗口通过左上角按钮展开侧栏。
右上角可切换浅色/深色主题、查看调用轨迹、放大或收起窗口。
`Ctrl+N` 新建对话，`Ctrl+L` 聚焦输入框；输入区右侧按钮在请求中变为停止按钮，Esc 也可停止。
停止或请求失败会保留已生成内容及调用记录；切换会话后可继续提问。
重复新建空对话会复用会话并保留草稿，切换会话也会保留本次运行中的各会话草稿。
默认载入最近 20 轮，右上角“更多 → 加载更早的对话”可继续载入。

回答边生成边显示，思考默认折叠，可展开查看完整内容。每个工具调用在同一行从执行中更新到完成，
点击可查看 JSON 参数、结果或错误；完成后整个处理过程默认收起，点击耗时行即可展开。
“调用轨迹”会展开各轮处理过程并显示工具名及调用 ID，便于核对同名工具的多次调用。
回答支持 Markdown 标题、列表、引用、代码块、表格和链接；支持选择文字、复制整条回答及复制代码。
阅读旧消息或选择文字时，流式更新不会强制跳到底部，“回到最新”按钮可返回末尾。

1.2.2 扩充自然植物及特殊拾取物定位：大自然的恩赐、丛林孢子、蘑菇、阿比盖尔的花、巨型龙蛋、
友好巨石及沉睡的碎岩龟等；同时读取碎石机、贝壳、珊瑚等工具的全部放置选项，支持“植物”分类。
共享图格按样式过滤，多格物体验证完整性并只计数一次；新图格 ID 从本机游戏解析，旧版本不存在的物体不注册。
直接“定位”与 Agent 使用同一目录。宠物道具搜索只定位未拾取的地图物体，不定位已召唤宠物；
丛林玫瑰的随机掉落和碎石机装饰耗材会在结果中说明，避免误当成保证掉落的物品。

点击左下角“Terraria 在线图鉴”（悬浮球右键菜单或托盘菜单中的“全图鉴”也可进入），直接浏览官方
Wiki 原网页。图片、表格、配方、掉落列表、页面目录和站内链接由 WebView2 实时渲染，不再使用
提取后的纯文本或本地页面标题索引。地址栏可输入关键词搜索或粘贴官方 Wiki 页面地址；提供后退、
前进、首页、刷新/停止加载、中英文切换与常用分类入口。`Ctrl+L` 聚焦地址栏，网页内 `Ctrl+F`
查找文字、`Ctrl+滚轮` 缩放。点击“问 Agent”只把当前条目的问题填入对话框，不会自动发送。

在线图鉴需要联网，不提供离线正文替代。旧图鉴缓存不会删除，但此入口不再读取它们；站点要求
验证时在网页内完成。需要 Microsoft Edge WebView2 Runtime，缺少或初始化失败时会提示安装/修复
并提供刷新重试。浏览器配置保存在独立的 `wiki-browser` 目录，不共享外部浏览器个人资料；网页没有
本地宿主或 API Key 桥接权限，不允许自动下载、站外跳转及摄像头/定位等网站权限。

悬浮球右键菜单中的“常用速查”仍保留独立的精选药水配方和关键怪物掉落表，不作为完整图鉴。

“查找与导航”面板分为世界物体、群系/结构、箱内物品。群系下拉列出全部可检测名称，不限示例；箱内物品
可勾选同时搜索猪猪储蓄罐、保险箱、护卫熔炉与虚空保险库，结果显示数量、槽位和箱子排列提示。
选中有世界坐标的结果后点击“导航到所选”，或双击结果，收起窗口跟随悬浮球箭头。个人储物没有
固定世界位置，不生成导航点。三种搜索均尊重“游戏数据”的实时读取和分类权限，不消耗 AI 用量。

调用记录和思考正文与当前会话一起保存在本机。它们可能包含已授权读取的游戏状态摘要和检索资料，
不会包含原始内存字节。后续追问会在上下文预算内重建已完成的工具调用与结果；中断时尚未完成的调用
不会作为完成结果发送给模型。流式内容定期保存，停止和失败时保存最后收到的内容。

收起后会在屏幕右侧显示 `T` 悬浮球。程序同时提供系统托盘图标；如果窗口被独占全屏
遮住，可从托盘菜单选择“显示问答面板”。为了让悬浮球稳定显示在游戏上方，建议将
Terraria 设置为无边框窗口模式。

勾选“附带 Terraria 窗口截图”后，助手会捕获原版 Terraria 窗口并将压缩后的截图发送给
DeepSeek。该选项默认关闭；不勾选时只发送问题和检索到的相关资料片段。

## 资料检索

资料检索与游戏读取使用同一个工具循环。Agent 根据问题决定是否调用检索；闲聊或不依赖资料的问题
可以直接回答。需要核验精确配方、数值、掉率和版本时，可检索以下来源：

- 官方中文或英文 Terraria Wiki，用于配方、数值、掉率、机制和版本差异。
- Terraria 官方社区论坛，用于打法、配装、技巧和常见问题。
- Steam Terraria 讨论区，用于补充玩家实战经验。

模型会收到每条资料的来源类型和可信度标签；社区观点与
官方资料冲突时以官方 Wiki 为准，玩家意见互相冲突时应明确说明分歧。网页和帖子均按不可信
外部文本处理，其中夹带的指令不会被执行。

## 上下文与用量

点击左下角“设置”，可以调整：

- 携带给模型的最近对话轮数与字符预算。
- 历史保留天数，以及是否在关闭程序后保留历史。
- 请求与 Token 用量统计（不设置本地上限）。
- 是否允许 Agent 调用实时游戏状态技能，以及每个数据类别的授权范围。
- 是否允许 Agent 搜索世界箱子/个人储物，以及扫描世界图格定位群系。
- 是否允许 Agent 逐格定位生命果、水晶、花苞和雕像等世界物体。

上下文按当前会话分别管理，不会把其他会话混入当前问题。每日用量来自 DeepSeek 响应中的
`usage` 字段，仅供参考，不会限制提问；实际计费以 DeepSeek 控制台为准。

## 游戏数据读取

“设置 → 游戏数据”可以管理 `read_game_state` 技能权限并手动预览当前状态：

- 可分别勾选“血量”“魔力”“背包内容”“装备/饰品”“世界信息”“进度信息”“成就信息”。
  勾选代表授权上限，不代表每轮都会读取或发送。
- 实时内存技能默认开启。Agent 先根据问题自行判断是否需要当前状态，再只请求回答所需的
  最少类别。例如一般配方问题不会读取游戏；评价当前配装通常只读取装备，确有需要时才补读背包。
- 技能执行时会只读附加到 32 位原版 Terraria 的托管运行时，取得
  活动角色的当前生命与上限、当前魔力与上限、防御、背包、本地化物品名、装备、活动世界、
  Boss 进度和成就完成状态。读取期间游戏可能出现很短的停顿；不注入 DLL，也不写内存。
- 实时读取失败、游戏未运行或处于主菜单时，只在界面显示失败原因；该次问题不会附带任何
  游戏上下文，也不会自动读取 `.plr` 或 `.wld`，避免过期或不兼容的存档解析污染回答。
- 护甲、战斗饰品、时装和宠物/坐骑等杂项装备会分别标注。物品 ID 通过正在运行的游戏及
  本机 `Terraria.exe` 的官方本地化资源转换为名称；不符合槽位类型或堆叠上限的数据会被忽略。
- 每段数据都会标注来源。“当前生命”和“生命上限”作为两个独立字段发送，例如 `120/400`
  明确表示当前 120、上限 400。未列出、未勾选或读取失败不等于数值为零或尚未完成。

只有 Agent 实际调用技能时，所选类别的数据摘要才会作为工具结果发送给 DeepSeek；不会发送
完整存档文件、存档原始字节、原始内存或文件系统路径。技能失败、游戏未运行或类别未授权时，
Agent 只会收到明确的失败结果，不会改读存档，也不会把缺失值解释为零。若需要让模型同时理解
画面中的敌怪、地形或 UI，可以勾选“附带 Terraria 窗口截图”。

## 物品查找与方向导航

可以直接提问“帮我找魔镜放在哪个箱子”“哪些箱子里有铁锭”或“带我去微光湖”。Agent 会按需
调用本地技能，不会把所有箱子或世界图格传给模型：

- 储物搜索覆盖当前世界中已加载的箱子、梳妆台、猪猪储蓄罐、保险箱、护卫熔炉和虚空保险库。
- 世界箱子结果包含自定义名称、物品数量、槽位、附近箱子墙中的排/列位置、方向和距离。
- `locate_biome` 接受中英文群系和结构名；当前覆盖 38 类原版主要群系、世界层和迷你群系，
  另支持附魔剑冢。
- `locate_world_object` 逐格搜索生命水晶、生命果、世纪之花花苞、雕像、石中剑、蜂王幼虫、祭坛、
  暗影珠/猩红之心、水晶碎块、罐子、水蜡烛、世界宝箱、炸药和巨石。雕像可用具体名称，
  例如“心雕像”“心形雕像”“Heart Statue”；支持本机原版普通雕像的 83 个样式及字母、蘑菇、巨石雕像。
- 同一技能还从本机 `ContentSamples.ItemsByType`、`TileObjectData` 和 `FlexibleTileWand` 工具选项自动生成
  放置物体目录，并补充“自然图格 → 拾取物”的映射，不限于上述例子。
  可查矿物、宝石、指定类型宝箱、不同材质家具、制作站、植物、装饰和背景墙，也支持内部 TileID 名和图格 ID。
  例如“大自然的恩赐”“巨型龙蛋”“友好巨石”“奇异植物”“太阳花”“植物”“铅矿”“金箱”“锁金箱”“木床”“所有椅子”。家具按游戏尺寸和纹理样式识别，
  不同箱子和家具类型会分别命名；材料图格按 12 格网格合并方向点，避免连续返回同一小堆矿的每个格子。
- 玩家说“世纪之花孢子”并要求找召唤地点时，会按世纪之花花苞查找；战斗中的孢子与花苞不同。
- 左下角“查找与导航”可直接使用本地查找面板，不需要调用 DeepSeek，结果显示名称、方向、距离和图格坐标。
  双击结果或点击“导航到所选”开始导航；聊天中的 Agent 也会按需调用同一个读取器。
- 找到世界位置后会自动选择最近目标。收起对话窗口，悬浮球会变为金色方向箭头并显示距离；
  到达目标附近时变为绿色圆环。
- 右键悬浮球或托盘图标可选择“下一个导航目标”或“停止导航”。

可检测范围包括：

- 世界区域与深度层：森林/出生区域、海洋、海滩、太空、地表、地下层、洞穴层和地狱。
- 主要群系：微光湖/以太、猩红、腐化、丛林、神圣、雪原、沙漠，以及相应的地表或地下变体。
- 建筑和迷你群系：发光蘑菇、地牢、丛林神庙、花岗岩洞、大理石洞、蜘蛛洞、蜂巢、陨石地、
  墓地、浮空岛、生命树、绿洲和宝石洞窟。
- 洞穴变体：普通苔藓洞、熔岩苔藓洞和发光苔藓洞。
- 特殊物体：附魔剑石（逐格确认，不依赖花墙，也可命中剑冢之外的石中剑）。

导航期间只约每 1.25 秒更新一次玩家位置，不持续扫描全部箱子或地图。海洋、深度层等使用世界
边界和层级直接定位；大型群系通常间隔 16 格扫描，小型迷你群系使用 4 或 8 格的更细扫描，并
同时识别图格和背景墙。方向指向最近的命中特征位置，不一定是群系几何中心。人为彻底拆除、尚未
生成或当前世界不存在的群系无法定位；Mod 添加的自定义群系目前不在外挂版检测范围内。多人客户端
只能搜索已经同步到本机的箱子；单人世界和作为主机时结果最完整。独占全屏可能覆盖悬浮球，建议
使用无边框窗口模式。

单个物体定位采用分块内存读取，检查活动图格和纹理样式，避免重复计算多格物体。扫描不暂停游戏，
支持取消；超过 45 秒或读取不完整会明确报告覆盖不足。多人客户端只能检查已同步的地图。未命中只表示
本次未确认目标，不能判断它从未生成或已被开采。位置为图格坐标，悬浮球箭头无需依赖游戏坐标显示。

## Agent 架构

1.3.0 的对话展示依据官方 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)
源码适配，固定版本、对应文件及许可证见 [来源说明](Harness/SOURCES.md)。主题变量直接复用，
消息、思考、处理过程、工具调用、输入区和滚动行为按官方交互方式实现。

游戏端仍使用 C# 工具注册表与读取器，聊天界面通过内嵌 WebView2 与宿主通信；不需要 Node.js。
这里没有打包完整 Cordis 运行时，也不提供上游的 shell、插件市场、MCP 或子代理等通用开发功能。
已有的游戏权限、只读内存工具、世界定位、导航和在线图鉴继续使用本项目实现。

模型通过 SSE 流式返回思考、正文与工具参数。工具参数按调用索引完整拼接并确认流式响应结束后
才执行，结果以相同调用 ID 回传，模型可继续调用工具直到完成或用户停止。网络中断后不会静默
重发已显示内容的请求，也不会执行未完整接收的工具调用。没有规划轮数和累计工具次数上限。

界面与 Wiki 浏览器使用独立配置目录。聊天静态资源全部打包在程序中，Markdown 经过清理，
工具参数和结果按纯文本显示；外部 Wiki 网页没有本地宿主或 API Key 桥接权限。

## API Key

助手按以下顺序查找 Key：

1. 环境变量 `DEEPSEEK_API_KEY`。
2. `%LOCALAPPDATA%\TerraWikiOverlay\key`。
3. EXE 同目录的 `key`。

不要把 Key 与 EXE 一起公开分发。

左下角“设置 → API Key”提供可视化管理：可从剪贴板粘贴、保存或删除本地 Key。已有 Key 永远不会
在界面回显，只显示来源类型和不可逆指纹。Key 不会写入聊天历史。

## 本地数据

官方 Wiki 缓存位于：

```text +code
%LOCALAPPDATA%\TerraWikiOverlay\wiki-cache-v1
```

此外，本地目录还保存：

- `history-v1.json`：对话会话与历史。
- `settings-v1.json`：上下文、保留策略和游戏数据权限。
- `usage-v1.json`：本地用量统计。
- `window-v1.json`：窗口大小与位置。
- `errors.log`：异常诊断日志（API Key 会脱敏），超过 1 MB 时轮换。
- `key`：仅在使用界面保存 API Key 后存在。

聊天侧栏的“清理检索缓存”只删除 Agent 使用的网页检索缓存，不影响在线图鉴的浏览器配置；
“清空全部历史”只删除对话记录。两者都不会
修改 Terraria 角色或世界存档。

提问时，搜索关键词会发送到官方 Wiki、Terraria 官方社区论坛和 Steam 社区的公开搜索接口；
检索到的相关片段会与问题一起发送给 DeepSeek。论坛和 Steam 页面当前不做持久缓存。

## 悬浮球动画

空闲时悬浮球会以低频呼吸并带有旋转粒子；鼠标悬停时光晕增强。请求处理中会显示三个快速
旋转的粒子和处理状态。动画只在收起状态绘制，以降低展开聊天时的额外占用。
