# Terra Agent 悬浮助手

支持原版 Terraria 和 tModLoader 的独立 Windows 悬浮助手。通过悬浮球在游戏中提问，
由 DeepSeek `deepseek-flash` 回答。助手可按需调用只读游戏状态、箱子物品搜索和群系定位技能，
并提供在线 Wiki 浏览器、多会话历史、Markdown 显示及用量统计。当前版本为 1.5.0。

1.5.0 支持 64 位 tModLoader：自动识别游戏客户端，共用对话、状态预览、物品查找、地图定位、
截图和悬浮球导航。无需安装配套 Mod 或重载世界；64 位读取器随 EXE 内置，使用 tModLoader
自带的 .NET 运行时。模组物品使用当前游戏的名称与 ID，支持额外饰品槽、模组前缀及加载列表。
群系定位目前覆盖原版主要群系在 tModLoader 世界中的位置；各模组自定义群系和 Boss 进度
不作通用推断，官方 Wiki 与精选速查仍是原版资料。

1.3.0 按 DeepSeek Harness 官方源码重做对话界面与交互：流式回答、可展开的思考、同一行更新的
工具调用、完整参数与结果、调用轨迹、浅色/深色主题，以及能保留中断内容的历史记录。
界面使用官方主题变量，源码出处与适配范围见 [来源说明](Overlay/Harness/SOURCES.md)。

1.4.0 将设置、API Key、用量、游戏权限、查找与导航、常用速查和图鉴工具栏统一到同一套界面。
在“设置 → 常规 → 外观”选择浅色、夜间或跟随系统；所有页面、图鉴浏览器、悬浮球和菜单同步切换，
下次启动会恢复选择。右上角太阳/月亮按钮也可快速切换。

1.4.1 更新悬浮球：透明边缘、轻微呼吸、悬停和按压过渡、连续旋转的执行光环，以及平滑转向的
导航箭头。执行工具时仍能查看导航距离。收起与展开复用窗口，隐藏悬浮球时停止逐帧渲染；
关闭 Windows 动画效果后，悬浮球使用静态状态提示。

1.4.2 加强待机和拖动特效：即使不悬停、没有执行任务，也持续显示蓝青色流光、环绕粒子和
内层光晕；拖动时光环加速，并产生随路径变化的发光拖尾，松手后显示扩散光圈，拖尾逐渐消散。
拖尾不拦截游戏中的鼠标点击，展开聊天后随悬浮球一起隐藏。

左下角“查找与导航”提供世界物体、群系/结构、箱内物品三种搜索方式，无需调用 AI。
“Terraria 在线图鉴”直接显示官方 Wiki 网页，支持中英文切换、站内搜索和浏览历史。
聊天中的资料检索与游戏工具统一由 Agent 按需调用，完成后可展开处理过程查看依据。

## 安装与启动

运行 [悬浮窗程序](dist/TerraWikiOverlay-single/TerraWikiOverlay.exe)。发布目录固定为 `dist/TerraWikiOverlay-single`。
首次启动会展开问答面板；
点击悬浮球可再次打开，或按 `Ctrl+Shift+T` 切换面板。建议将 Terraria 设为无边框窗口模式，
以便悬浮球保持可见。左下角“设置 → API Key”可导入 DeepSeek Key。
在线图鉴需要联网及 Microsoft Edge WebView2 Runtime；本机已安装即可直接使用，缺少时会给出安装入口。

项目源码可用以下命令发布为单文件 Windows 程序：

```powershell
.\tools\Build-Overlay.ps1
```

源码与变更使用 Git 管理，发布版用 `v版本号` 标签记录。`dist` 中仅保留当前程序，回退时从对应
标签构建；例如 `git switch --detach v1.4.0` 后运行发布脚本。切换前应先提交工作区改动，
发布前从托盘退出目标目录中的程序。`publish-info.json` 记录程序版本、源码提交与构建时工作区
是否有改动，便于核对运行的是哪一版。Git 不收录发布程序、本地 Key、设置和历史。

完整使用说明和隐私边界见 [悬浮助手文档](Overlay/README.md)。本地 Key、设置、历史和缓存保存在
`%LOCALAPPDATA%\TerraWikiOverlay`，不会随程序更新删除。不要公开分享 Key。
